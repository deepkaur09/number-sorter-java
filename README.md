# Number Sorter

A Java program that reads a list of numbers from a CSV file, sorts them,
and computes how often each number appears.

## Input
`numbers.csv` — the numbers to process.

## Output
`sorted_num.csv` — the sorted list
`num_frequency.csv` — each number and its frequency

## Running it
Compile with `javac SortNums.java` and run with `java SortNums`.
The input file must be in the same directory.

Coursework project, CS 12400, Fall 2025.
